탭 동작 요약
  • Small: 위젯 전체 탭 → /quotes/{id}
  • Medium: 명언 영역 탭 → /quotes/{id}, 저자 탭 → /authors/{slug}
  • Large: 영역별 개별 탭 + Interactive 버튼
  • Lock Screen: 위젯 탭 → 앱 실행
  • Mac: 클릭 → Safari에서 사이트 열기
